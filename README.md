## 🎯 AI Code Editors

### [Cursor](https://cursor.sh)
The AI-first code editor built on VSCode. Natural language editing, codebase-aware chat, and seamless GitHub Copilot integration.

### [Windsurf](https://codeium.com/windsurf)
Codeium's AI IDE with multi-file editing and autonomous coding flows.

### [Zed](https://zed.dev)
Lightning-fast collaborative editor with built-in AI assistance.
